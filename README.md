# Shinji Yamashita Portfolio

Personal portfolio built with React, TypeScript, Vite, and a dependency-free WebGL1 shader.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

This project is ready for Vercel. Import the GitHub repository in Vercel or run `vercel` from the project directory.
